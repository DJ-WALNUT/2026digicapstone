## 1. 발표에서 쓰기 좋은 핵심 사례

| 사례 | 한 줄 요약 | 비교 이미지 (`전후비교/`, 왼쪽 전, 오른쪽 후) |
|---|---|---|
| A. 오른팔에 달린 왼손 (26) | "오른손"이라고 써도 왼손이 나왔다. 참고 이미지까지 점검하고 손의 앞뒤 순서를 설명해 해결 | `06_CUT26_왼손오류` |
| B. 벗겨진 소매 (26) | 손가락을 쥐라는 지시에 소매가 벗겨지고 구체관절 팔이 나타났다. 움직일 곳과 멈출 곳을 나눠 해결 | `07_CUT26_소매벗겨짐` |
| C. 눈을 깜빡인 인형 (27) | 다시 생성하지 않고 인형만 줄이고 정지시켜 합성했다 | `08_CUT27_인형크기와깜빡임` |
| D. 게임 화면 같은 구도 (34 → 33·35·36) | 첫 이미지의 구도가 영상의 인상을 정했다. 구도를 영화처럼 바꿔 다시 만들었다 | `01_CUT34_게임같은구도`, `02_CUT33_구도재작업` |

**전체를 묶는 메시지(제안):** AI에게 "잘 만들어 달라"고 하는 것보다, **통제할 것을 먼저 정하고(첫 장면 이미지, 음성, 카메라) 나머지를 생성하게** 했을 때 결과가 안정됐다.

## 2. 문제 해결 기록

### 2-1. 인물과 인형의 일관성
| 문제 | 원인 | 해결 | 배운 점 |
|---|---|---|---|
| 립싱크 컷에서 얼굴 비율과 입모양이 무너짐 (08, 시험 E1~E3) | 참조 시트를 넣고 영상이 얼굴까지 만들게 함. 입모양 시트가 입술을 튀어나오게 함 [추정] | 얼굴·손·구도를 **첫 장면 이미지에서 먼저 확정**하고 첫 프레임과 음성만 넣음 (E4~E6, 여섯 번째에 합격) | 영상 단계에서 얼굴을 만들게 하지 않는다 |
| 주인공 얼굴이 인형처럼 섞임 (시험 D1) | 서연을 닮은 인형 시트를 함께 첨부 [추정] | 인형 시트 전체 대신 첫 장면 이미지 사용 | 닮은 두 캐릭터의 시트를 같이 넣지 않는다 |
| 인형이 목표보다 큼 (18b, 18c, 19, 23) | 글로만 크기를 지시 [추정] | 목표 크기를 **분홍 도형**으로 그린 안내 이미지를 첨부. 모두 합격 | 크기는 글보다 그림으로 지시한다 |
| 지민의 앞모습은 긴 웨이브인데 뒷모습은 똥머리 | 턴어라운드의 각도마다 머리 모양이 달라짐 | 원본이 남아 있지 않아 "모든 각도에서 푼 머리"를 명시해 새로 생성 | 캐릭터 시트는 각도별로 대조한다 |

### 2-2. 첫 장면 이미지
| 문제 | 원인 | 해결 | 배운 점 |
|---|---|---|---|
| 34가 게임 대화 화면처럼 보임 | 인물이 가운데 정면이고 뒤에 학생이 줄지어 있음. 프리비즈 구도도 영향 | 인물을 한쪽으로 치우치고 앞에 흐린 물체, 낮은 역광, 줄인 색으로 재제작. 같은 기준으로 **33, 35, 36 등 11장을 재작업** | 첫 이미지가 영화 같아야 영상도 영화 같다 |
| 걱정 인형이 07보다 먼저 서연과 똑같은 모습으로 나옴 (01~03) | SNS 이미지의 인형을 서연 인형으로 그림 | SNS의 인형을 서연과 닮지 않게 교체 | 컷마다 예뻐도 이야기 순서로 다시 검사한다 |
| 07의 인형이 서 있어 버려진 물건처럼 보이지 않음 | 정면으로 선 인형 [추정] | 벽에 기대앉은 인형으로 교체하고 스틸을 느리게 확대 (`03_CUT07_인형자세`) | 모든 컷을 생성 영상으로 만들 필요는 없다 |
| 26이 오른팔에 왼손 | 프롬프트에는 "오른손"이라고 썼지만 참고 이미지(C04b)의 손이 왼손 [추정] | 참고 이미지에서 엄지를 잘라내고, "새끼손가락이 카메라에 가깝고 엄지는 반대편"처럼 **보이는 순서로 설명** | 왼쪽·오른쪽이라는 말보다 화면에서 보이는 모습으로 지시하고 첨부 이미지도 점검한다 |

### 2-3. 영상 생성
| 문제 | 원인 | 해결 | 배운 점 |
|---|---|---|---|
| 고개가 지시보다 크게 돌아감 (34 시험, 12, 24) | 20도나 "몇 도"라고 써도 크게 움직임 [확인: 여러 컷에서 반복] | 34는 시선만 옮기게 하고, 12는 큰 회전을 잘라낸 뒤 조금 돌아간 자세에서 정지(`05_CUT12_고개과다회전`), 24는 좋은 구간만 사용 | 각도 숫자는 통하지 않는다 |
| 26 v1에서 소매가 벗겨지고 구체관절 팔이 나타남 | 손을 쥐는 동작에 팔 전체가 움직임 [추정] | "손가락 끝만 움직이고 소매와 팔은 완전히 정지"로 나눠 지시. v2 합격 | 움직일 곳만이 아니라 **멈출 곳을 명시**한다 |
| 정지해야 할 인형이 움직임 (08b, 23, 27) | 얼굴이 있는 물체를 살아 있는 것처럼 움직임 [추정] | 08b는 물건이라고 설명하고 첫·끝 프레임이 같다고 명시. 23·27은 인형 부분을 정지 화면으로 덮음 | 카메라를 고정해 두면 후반 보정이 가능하다 |
| 27의 인형이 다음 컷보다 큼 | 첫 장면 이미지부터 크게 그려짐 | 인형 주변을 0.83배로 줄여 합성하고 하늘 밝기를 맞춤 | 앞뒤 컷과 나란히 놓고 크기를 확인한다 |
| 09의 문에 손잡이가 하나 더 생김 | 문이 닫히며 영상이 새로 그려짐 [추정] | 2.73초 뒤로 문을 정지 화면으로 덮음 (`04_CUT09_손잡이중복`) | 좋은 부분은 살리고 문제 부분만 덮는다 |
| 15b 뒤쪽에서 인형 똥머리가 사라짐 | 손에 가려진 부분이 바뀜 [추정] | 2.6초에서 자름 | 5초를 다 쓰려고 하지 않는다 |
| 37A의 거울에 사람이 나타남 | "아무도 비치지 않는다"고 썼지만 거울에 가까워지자 생김 [확인: 영상], 이유는 [추정] | 4.1초에서 잘라 38A로 연결 (`09_CUT37A_거울에비친사람_왼쪽이사용구간`) | 반사면은 끝까지 확인한다 |
| 카메라 참고 영상의 초록 기둥과 흰 벽이 섞임 (31) | 첫 프레임에 없던 곳을 프리비즈 형태로 채움 [확인] | 참고 영상을 빼고 문장으로만 카메라를 지시. 31은 2.7초까지 사용 | 첫 프레임 밖이 보이는 카메라 움직임을 피한다 |
| 작은 봉제선이 뭉개짐 (34) | 작은 무늬가 영상에서 유지되지 않음 | 34b(귀 뒤), 35b(지민 손)를 **스틸 클로즈업**으로 추가 | 중요한 단서는 스틸로 보여 준다 |

### 2-4. 음성
| 문제 | 원인 | 해결 | 배운 점 |
|---|---|---|---|
| 타입캐스트의 억양이 기계적임 | 서비스의 음성 특성 | 일레븐랩스로 전환하고 스토리보드 상황을 근거로 연기를 지시 | 짧은 대사는 감정 태그보다 문장부호의 영향이 컸다 |
| 같은 견본을 넣어도 영상마다 목소리가 달라짐 (시험 D, D1↔D2 5.2반음) | 영상 생성기가 목소리를 매번 새로 만듦 [확인] | 목소리 견본 방식을 쓰지 않음 | 목소리는 영상과 따로 확정한다 |
| 첨부한 음성이 그대로 쓰이지 않음 (34: 약 2반음 상승) | 첨부 음성도 다시 만듦 [확인] | 첨부 음성은 입모양 참고용으로만 쓰고 편집에서 원본을 덮음 | 처음에는 "그대로 들어간다"고 판단했다가 **다시 측정해 바로잡았다** |
| 2초 이하 음성이 업로드되지 않음 (33, 34) | 드리미나 제한 | 앞뒤에 무음을 붙인 업로드용 파일을 따로 만듦 | 업로드용과 편집용을 구분한다 |

### 2-5. 화면·기술 규격
| 문제 | 원인 | 해결 | 배운 점 |
|---|---|---|---|
| 결과가 60fps의 매끄러운 3D처럼 보임 | 스톱모션 문구("animated on twos")가 반영되지 않음 | 편집에서 12fps로 줄이기로 함 (편집 전) | 질감은 후반에서 만든다 |
| 정지 화면 보정이 엉뚱한 프레임에서 멈춤 (12) | 60fps로 표시되지만 실제 프레임은 121장(약 24fps) [확인] | 프레임을 직접 세어 다시 편집 | 표시된 값을 믿지 말고 프레임을 확인한다 |
| 720p 설정인데 1920×1088로 저장됨 | 확인하지 못함 | 편집에서 위아래 4픽셀씩 자르기로 함 (편집 전) | - |
| 높은 해상도로 모두 만들면 크레딧 부담 | - | 720p로 생성하고, 편집 확정 뒤 쓴 클립만 업스케일하기로 함 (편집 전) | - |
