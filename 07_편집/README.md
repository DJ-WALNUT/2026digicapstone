# 가편집 v1 (2026-11-26)

| 파일 | 쓰는 곳 |
|---|---|
| `대체품_가편집_v1_컷번호.mp4` | **먼저 볼 것.** 컷 번호, 시작 시간, 자막이 보이는 720p 확인용 |
| `대체품_가편집_v1.mp4` | 표시가 없는 1080p |
| `대체품_가편집_v1_12fps.mp4` | 스톱모션 질감 미리보기 |
| `대체품_가편집_v1.xml` | Premiere: 파일 > 가져오기. `클립`, `대사` 폴더가 이 자리에 있어야 한다 |
| `대체품_가편집_v1.srt` | 자막 |
| `클립/`, `대사/` | XML이 쓰는 원본. 클립은 5초 전체라 컷 길이를 늘이고 줄일 수 있다 |
| `make_rough.py` | 컷 순서, 구간, 대사 시점을 고쳐 다시 만드는 스크립트 |

- 대사는 크기를 비슷하게 맞춘 복사본이다. 원본은 `03_대본/tts_최종`.
- 확대(01~03, 18, 20, 24b, 27, 28, 34b, 39)는 클립에 들어 있다. 바꾸려면 스크립트에서 고친다.
- 효과음, 음악, 색보정, 업스케일은 아직 없다.
