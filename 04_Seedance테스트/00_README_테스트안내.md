# Seedance 테스트 (CUT 14 · 08 · 10)

목적: 본 제작 전에 **Higgsfield Seedance가 무엇을 할 수 있는지** 확인해서 프리비즈·TTS 작업 방식을 정한다.
테스트당 5초 안팎 1~2회 생성이면 충분하다.

| 순서 | 테스트 | 컷 | 확인할 것 | 결과로 정해지는 것 |
|---|---|---|---|---|
| 1 | **B** — 참고 영상 | CUT 14 마네킹으로 느린 접근 | 회색 블로킹 영상의 **카메라 무빙만** 따라 하는가 | 프리비즈를 **카메라 애니메이션 영상**으로 만들지, **구도 스틸**로 가볍게 만들지 |
| 2 | **C** — 립싱크 | CUT 08 "너… 나 닮았다." | 타입캐스트 음성을 넣으면 **입모양이 맞는가** | 립싱크 6줄 작업 방식 (음성 먼저 → 영상 / 영상 먼저 → 편집에서 맞춤) |
| 3 | **A** — 이미지 참고 | CUT 10 책상 고정 와이드 | 참고 이미지만으로 **서연 얼굴·옷, 방 배치가 유지되는가** | 컷별 **첫 장면 콘티 이미지**가 꼭 필요한지 |

## 폴더
```
04_Seedance테스트/
├─ 00_README_테스트안내.md      ← 이 문서
├─ 결과기록.md                   ← 생성할 때마다 한 줄씩 기록
├─ TEST_A_CUT10/프롬프트_TEST_A.txt
├─ TEST_B_CUT14/
│  ├─ 프롬프트_TEST_B.txt
│  ├─ TEST_B_CUT14_blocking.mp4   ← 참고 영상 (5초, 1280×720, 24fps / 레포 제외·로컬 전용)
│  └─ TEST_B_CUT14_blocking.blend ← 영상 원본 (다시 렌더 가능)
└─ TEST_C_CUT08/
   ├─ 프롬프트_TEST_C.txt
   ├─ make_tts.py                  ← 타입캐스트 API로 대사 음성 생성
   ├─ .env.example                 ← API 키 넣는 양식 (.env 로 복사해서 사용)
   └─ audio/                       ← 생성된 wav (레포 제외)
```
첨부 이미지는 모두 `01_기준에셋_결과물/` 에 있다.

## 공통 작업 방법 (Higgsfield)
1. 모델: **Seedance 2.0** (참고 이미지 최대 9장·영상 3개·음성 3개, 4–15초). 2.5가 열려 있으면 2.5도 OK. 어느 쪽을 썼는지 기록.
2. 화면비 16:9, 해상도는 1080p면 충분 (테스트는 크레딧 아끼기).
3. 각 txt의 **첨부 순서대로** 올리고, txt 안의 프롬프트 블록을 통째로 붙여넣기.
   - 앱이 `@Image1`, `@Video1`, `@Audio1` 같은 태그로 참조하는 방식이면 프롬프트의 "image 1" 등을 그 태그로 바꾼다.
   - 첫 프레임(start frame) 지정 칸이 따로 있으면 txt에 적힌 대로 지정.
4. 결과는 드라이브에 `TEST_B_CUT14_B1_v1.mp4` 형식으로 저장 (영상은 레포에 올리지 않음).
5. `결과기록.md` 에 한 줄 기록.

## TEST B — 참고 영상 (가장 먼저)
- 첨부: `L01_방_아침.png` + `TEST_B_CUT14/TEST_B_CUT14_blocking.mp4`
- 블로킹 영상 = 방문 쪽 구석(BLK_방_와이드 구도)에서 마네킹 쪽으로 5초 돌리 인. 회색 상자 그대로라 **"모양·색·조명은 따라 하지 말고 카메라 움직임만"** 이라고 프롬프트에 적어 둠.
- **B1(참고 영상 있음)과 B2(없음, 텍스트만)를 같은 조건으로 1회씩** → 참고 영상이 실제로 도움이 되는지 비교.
- 판정
  - B1이 무빙 경로·속도·끝 구도를 따라 함 → 프리비즈 = **컷별 카메라 애니메이션 렌더**
  - B1과 B2가 비슷하거나 B1이 회색 화면을 따라 함 → 프리비즈 = **첫 장면 구도 스틸 + 무빙 문장**

## TEST C — 립싱크
1. **API 키 준비** (사용자): 타입캐스트 API 콘솔 → 키 발급 → `TEST_C_CUT08/.env.example` 을 복사해 `.env` 로 이름 변경 → `TYPECAST_API_KEY=` 뒤에 붙여넣기
2. 터미널에서 `TEST_C_CUT08` 폴더로 이동 후
   ```
   python make_tts.py voices              # 서연 후보 목소리 목록 (여성·청년), 미리듣기 링크 포함
   python make_tts.py make --voice tc_xxx # 고른 목소리로 테이크 3개 생성
   ```
   → `audio/CUT08_서연_너나닮았다_take1_smart.wav` / `take2_normal` / `take3_happy` (각 길이 출력)
   - 고른 voice_id는 `.env` 의 `TYPECAST_VOICE_ID` 에 적어 두면 다음부터 `--voice` 생략 가능
   - **같은 목소리를 대체품(CUT 31 이후)에도 쓰므로** 목소리 선택이 사실상 확정 단계
   - Claude에게 맡기려면 `.env` 만 채워 두고 "TTS 생성해줘"라고 하면 됨 (키를 채팅에 붙여넣지 않아도 됨)
3. Seedance: C01·C02·C03·L02_골목_밤 + 고른 wav 1개 → `프롬프트_TEST_C.txt` C1
4. 비교용 C2: 음성 없이 Seedance가 목소리까지 만들게 해서 입모양·발음 비교
- 판정
  - C1 입모양이 맞음 → 립싱크 6줄은 **TTS 먼저 → 음성 첨부해서 영상 생성**
  - 안 맞음 → 영상은 무음으로 만들고 편집에서 음성을 맞춤 (입이 크게 안 보이게 구도 조정)

## TEST A — 이미지 참고
