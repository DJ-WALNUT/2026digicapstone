# 영상 생성 순서

모두 **5초, 16:9, 720p**. 컷 폴더에서 `1_첫프레임`을 첫 프레임에 올리고, `프롬프트.txt`의 `===== 복사 =====` 밑을 붙여넣는다.
**음성은 폴더에 wav가 있는 컷(15a, 33, 36a, 36b)만 올린다.** 참고 영상은 어느 컷에도 올리지 않는다(시험에서 프리비즈가 섞임). 나머지 대사는 편집에서 덮는다.
결과는 `05_본제작/CUTxx/CUTxx_영상.mp4`로 저장. 다시 만들면 `_v2`.

| 순서 | 컷 | 볼 것 |
|---|---|---|
| ✅ 1묶음 합격 (11-25) | 32, 23, 06 | 31과 이어지는지 / 인형이 가만히 있는지 / 얼굴 유지 |
| ✅ 2묶음 합격 (11-25) | 04, 07, 09 | 07은 스틸 확대, 09는 문 정지 보정본 |
| 3묶음 | 12, 15b, 16 | 12는 고개가 몇 도만, 손가락 |
| 4묶음 | 19, 20, 21 | 봉제선이 커지지 않는지, 거울 속 동작 일치 |
| 5묶음 | 24, 25, 26, 27 | 손가락, 봉제선, 얼굴 |
| 6묶음 | 28, 29, 30, 37A | 어두운 곳 뭉개짐, 1인칭에 몸·반사 없음 |
| 7묶음 (첫 프레임 준비 완료) | 15a → 33 → 05, 11, 13, 35 → 36a → 36b | 15a·33은 입모양 먼저 확인, 35·36 목의 봉제선이 커지지 않는지 |

- 1묶음이 확인되면 2~6묶음은 이어서 만들어도 된다.
- 7묶음에서는 **립싱크인 15a와 33을 먼저** 만들고 확인한다.
- **36b는 36a 영상의 마지막 장면**이 첫 프레임이다.
- 38A, 39는 이미지를 그대로 쓴다. 한 컷이 세 번 실패하면 멈추고 프롬프트를 고친다.
