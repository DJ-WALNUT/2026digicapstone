# 콘티 재작업 4차: 인형으로 변해 가는 흐름

보는 사람이 **사람 → 인형** 변화를 한눈에 느끼도록 11장을 다시 만든다. 컷마다 정해 둔 "정도"를 넘기지 않는 것이 중요하다.

## 순서와 정도 (0 사람 ~ 5 완전한 천 인형)

| 순서 | 컷 | 정도 | 새로 보일 것 | 먼저 합격해야 할 것 | 영상 |
|---|---|---|---|---|---|
| 01 | 21 | 1 | 목덜미 봉제선 4~5땀 | | O |
| 02 | 22 전 | (인형) | 처음 주운 펠트 인형 얼굴 | | |
| 03 | 24b (새 컷) | 1.5 | 귀 뒤에서 목덜미까지 긴 봉제선 | | |
| 04 | 26 | 2 | 손등이 천으로 변함 | | O |
| 05 | 27 | 2.5 | 귀·목·볼 가장자리가 천, 긴 봉제선 | | O |
| 06 | 28 | 2.5 | 27과 같은 상태로 잠듦 | **05** | O |
| 07 | 34 | 0.5 | 33의 민준과 같은 퍼펫 얼굴 | | O (음성) |
| 08 | 34b | 1 | 귀 뒤에서 옷깃까지 봉제선 | **07** | |
| 09 | 35 | 1.5 | 턱선을 따라가는 봉제선 | | O |
| 10 | 36a | 2 | 거울 속 대체품과 같은 질감 | **07** | O (음성) |
| 11 | 36b | 3 | 턱선·목 봉제선, 유리구슬 눈 | **10** | O (음성) |

서연은 01~06, 친구들은 07~11이다. 두 사람이 나눠 동시에 해도 된다.

## 방법
1. 폴더의 `프롬프트.txt`에 적힌 순서대로 첨부하고, `===== 아래부터 복사 =====` 밑을 붙여넣는다. 이미지 생성은 ChatGPT를 먼저 쓴다.
2. 컷마다 새 대화를 연다. 고칠 때는 같은 대화에서 그 부분만 고쳐 달라고 한다.
3. `결과물/`에 적힌 이름으로 저장한다. 다시 만들면 `_2`, `_3`을 붙이고 이전 것도 남긴다.
4. **이미지가 합격한 뒤에** `영상프롬프트_이미지합격후.txt`로 영상을 만든다. 5초, 16:9, 720p.
5. 이미지를 **첫 프레임 자리**에 올린다. `영상용_` wav가 있는 컷만 음성을 함께 올린다.

## 하지 않는 것
- 27, 28에서 얼굴 전체를 인형으로 만들지 않는다. 완전한 인형은 39에서 처음 보인다.
- 36b도 완전한 천 인형으로 만들지 않는다. 40의 거울 속 대체품 수준까지만.
- 봉제선은 문신이나 상처가 아니라 **실로 꿰맨 자국**이어야 한다.

## 다시 만들지 않는 컷
- 20은 귀 쪽으로 확대해 봉제선을 키우고, 다시 작아 보이는 인형을 화면 밖으로 뺀다 (편집).
- 25는 봉제선이 보이는 앞 1.5초 위주로 쓴다 (편집).
- 35b, 38A, 39, 40은 그대로 쓴다.
