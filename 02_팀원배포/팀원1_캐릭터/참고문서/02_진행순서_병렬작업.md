## 0. 한눈에 보기

- **기준 에셋**: Gemini/GPT로 만드는 캐릭터·장소·소품 기준 이미지 (프롬프트는 이 폴더의 C01~P01 문서)
- **프리비즈**: Blender에서 공간 배치·카메라 구도·비율을 잡는 작업 (Claude가 Blender MCP로 진행)
- 두 작업은 **대부분 병렬로 가능**합니다. 단, **장소 이미지는 Blender 블로킹 렌더가 나온 뒤**에 만들어야 프리비즈·기준 이미지·Seedance 영상이 같은 공간으로 이어집니다.

## 3. 의존 관계도

```
[이미지] C01 ──┬─▶ C02
              ├─▶ C03 ──▶ C04a, C04b ──▶ C04c
              ├─▶ C05 ─────────────────┐
              └─▶ P01-3 (C03 이후)       │
                                       ▼
[Blender] 방·골목·강의실·화장실 블로킹 ─▶ 렌더 ─▶ L01~L04, P01-1, C04c
                                       ▲
                     C01 완성 → Blender 캐릭터 비율 수정
```

## 5. 파일 주고받기 규칙

```
2026 replicant/
├─ 01_기준에셋_결과물/   ← 팀원이 만든 기준 이미지 (C01_주인공_턴어라운드.png 등)
├─ Blocking/
│  ├─ blend/           ← 블로킹 Blender 파일 (예: L01_서연방_blocking.blend)
│  └─ render/          ← 팀원에게 보낼 BLK 렌더 6장
└─ Previs/             ← 이후 정식 프리비즈 (컷별 카메라·애니메이션)
```

- 생성한 기준 이미지 → `01_기준에셋_결과물/` 에 **각 문서에 적힌 파일명 그대로** 저장 (예: `C01_주인공_턴어라운드.png`)
- Blender 블로킹 렌더 → `Blocking/render/` — 파일명: `BLK_방_와이드` · `BLK_방_4방향` · `BLK_골목_와이드` · `BLK_골목_현관POV` · `BLK_강의실_입구POV` · `BLK_화장실_거울정면` · `BLK_강의실_거울정면`(엔딩 A안) (.png)
- Blender 블로킹 파일 → `Blocking/blend/` (장소별 1개: `L01_서연방_blocking.blend` …)
- 정식 프리비즈 파일 → `Previs/`
- **팀원은** 받은 BLK 렌더를 자기 zip의 `결과물/` 폴더에 넣으면 됩니다 (파일명만 맞으면 OK)
- 새 이미지가 들어오면 다음 단계 담당자에게 알려 주기
