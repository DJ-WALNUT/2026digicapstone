## 2. 도구 선택 팁

- **Gemini (이미지 생성/편집)**: 여러 장 첨부 시 캐릭터 동일성 유지가 강함 → 캐릭터·장소 시트에 사용.
- **ChatGPT 이미지 생성**: 레이아웃·라벨·한글/영문 텍스트가 들어간 시트에 강함 → 소품 시트, SNS 화면에 사용.
- 한 번에 완벽하게 나오지 않으면 **같은 대화창에서** "얼굴은 그대로, ○○만 수정"처럼 부분 수정 요청. 새 대화를 열면 일관성이 떨어집니다.
- 프롬프트는 **영문 본문을 그대로 복사**해 붙여넣고, 첨부 이미지는 각 문서의 "첨부" 목록 순서대로 올리세요.
