# 01. 스타일 바이블 (모든 프롬프트 공통)

**확정 화풍: 주인공 3D 디자인 × 스톱모션 퍼펫 애니메이션**
세상 전체가 1:6 스케일 미니어처 세트와 퍼펫으로 "실제 촬영"된 것처럼 보이게 합니다. 사람도 퍼펫, 걱정 인형은 그 세계 안의 더 거친 천 인형 → **사람이 천 인형이 되어가는 변형이 화풍과 자연스럽게 이어짐.**

모든 이미지 프롬프트의 **맨 앞**에 아래 STYLE BLOCK을 붙여 넣으세요. 각 문서의 프롬프트에는 `[STYLE BLOCK]` 자리로 표시해 두었습니다.

## STYLE BLOCK (복사용)

```
STYLE: handcrafted stop-motion puppet animation film, photographed for real on a miniature set (1:6 scale), based on the stylized 3D character design in the attached references. Characters are physical puppets: smooth matte resin/silicone faces with subtle hand-painted blush and freckles, slightly oversized glassy eyes, hair sculpted from real fibers, clothes tailored from real miniature fabric with visible weave, fuzz and stitching. Sets are handmade miniatures: real wood grain, paper, tiny props, slight imperfections, faint fingerprints and dust. Practical miniature lighting, macro lens look with shallow depth of field, subtle film grain. Mood: quiet psychological horror hidden inside a cozy, warm everyday world. Color: warm amber / tungsten practical lights, deep brown shadows, muted olive and charcoal accents. Keep proportions, face shape, hairstyle and clothing EXACTLY consistent with the attached reference images. No text, no watermark, no logo unless asked.
```

## 퍼펫 vs 걱정 인형 — 재질 구분 (중요)

| | 사람 (퍼펫) | 걱정 인형 / 인형화된 부위 |
|---|---|---|
| 피부 | 매끈한 무광 레진·실리콘 | **펠트·플리스 천**, 보풀 |
| 이음새 | 거의 보이지 않음 | **손바느질 봉제선**(검은 크로스 스티치) |
| 눈 | 유리질 눈, 반사광 | 구슬(비즈) 눈, 단순 반사 |
| 머리카락 | 섬세한 섬유 | 굵은 털실 |

→ 변형 = **레진 피부가 펠트 천으로 바뀌고 봉제선이 생기는 것**. 피·상처 없음.

| 금지 | 실제 브랜드 로고, 실존 SNS UI 그대로 재현, 고어/유혈, 매끈한 CG 느낌 |

## 영상화(Seedance) 시 스톱모션 느낌 유지 메모

- 영상 프롬프트에 `stop-motion animation, animated on twos (12 fps), slight frame-to-frame jitter, puppet movement` 추가.
- 카메라 무빙은 느리고 기계적으로(모션컨트롤 리그 느낌). 핸드헬드는 최소화.
- 편집 단계에서 12fps로 프레임 드롭하면 스톱모션 질감이 더 살아남 (CapCut/Premiere에서 가능).

## 공포 연출 원칙

- 기괴함은 **작은 디테일**(봉제선, 펠트 질감, 미세한 비대칭)로만. 얼굴을 괴물처럼 만들지 않는다.
- 친구들은 **웃고 평범하게** 행동 → 봉제선과의 대비로 공포.
- 인형은 귀엽지만 **눈이 약간 너무 오래 응시하는 느낌**.
